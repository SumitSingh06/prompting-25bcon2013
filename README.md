# Factorial in Python

A beginner-friendly Python program that calculates the factorial of a number using a `for` loop.

## What This Program Does

The program:

- Uses `n = 5` as the input value.
- Calculates the factorial of `n`.
- Uses a `for` loop to multiply the numbers from `1` to `n`.
- Prints the calculated factorial.

For the current value of `n`, the program calculates:

**5! = 120**

## How to Run

### 1. Clone or download the repository

Make sure `factorial.py` is available on your computer.

### 2. Open the terminal

Navigate to the folder containing `factorial.py`.

### 3. Run the program

```bash
python factorial.py
```

If your system uses `python3`, you can run:

```bash
python3 factorial.py
```

## Learning Objective

This program is designed for beginners to practice:

- Python variables
- `for` loops
- The `range()` function
- Multiplication and assignment
- Printing output using `print()`
